# v1.2.0 Release Announcement

Atlas Enterprise v1.2.0 is a validation-first release for the next runtime phase.

## What Changed

- Added executable Position persistence gates.
- Added backup schema compatibility validation.
- Added CSV import security validation.
- Wired the new gates into quick, feature, full, and release validation profiles.
- Verified GitHub Actions, GitHub Pages deployment, and live Pages browser smoke.

## Runtime Boundary

This release does not add Position persistence, backup schema mutation, or CSV import runtime behavior. It only adds the executable gates needed before those runtime batches can be selected.
