# v1.2 Position Persistence Test Scope

## Scope

This document defines the required tests before Position persistence can enter a runtime implementation batch.

## Required Tests

| Test Area | Required Coverage | Validation Command |
| --- | --- | --- |
| Repository Contract | create, update, list by owner, list by portfolio, reject cross-owner access | `npm run test:local-repositories` |
| Migration Chain | positions store creation, indexes, existing user data preservation | future migration validation |
| Backup Export | positions included only after backup schema version is accepted | `npm run test:backup-restore-e2e` |
| Restore Dry Run | reports positions count, rejected future versions, checksum result | `npm run test:backup-restore-e2e` |
| Owner Isolation | ownerId and householdId required for every persisted record | `npm run validate:backup-security` |
| Runtime Boundary | no broker API, market API, cloud database, or backend dependency | `npm run validate:runtime-boundaries` |
| Projection Compatibility | portfolio projections work with zero position records | `npm run validate:feature` |

## Exit Gate

Position persistence remains blocked until every required test area has an executable test or a documented rejection.
