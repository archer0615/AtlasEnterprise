# v1.2 CSV Import Fixtures

## Scope

CSV import fixtures define deterministic files needed before implementation.

## Fixture Set

| Fixture | Purpose | Expected Result |
| --- | --- | --- |
| `assets-valid.csv` | Valid Asset rows | dry-run accepted |
| `liabilities-valid.csv` | Valid Liability rows | dry-run accepted |
| `cashflow-valid.csv` | Valid Income and Expense rows | dry-run accepted |
| `goals-valid.csv` | Valid Goal rows | dry-run accepted |
| `mixed-valid.csv` | Mixed supported entity rows | dry-run accepted |
| `unknown-entity.csv` | Unsupported entityType | rejected |
| `missing-required-columns.csv` | Missing id, ownerId, amount/value | rejected |
| `duplicate-ids.csv` | Duplicate records | rejected before write |
| `formula-injection.csv` | Spreadsheet formula prefixes | rejected or escaped in report |
| `malformed-encoding.csv` | Malformed CSV quoting or encoding | rejected |

## Rule

Fixtures must be local files and must not require network, cloud storage, or user secrets.
