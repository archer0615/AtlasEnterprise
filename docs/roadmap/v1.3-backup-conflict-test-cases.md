# v1.3 Backup Conflict Test Cases

## Scope

These test cases cover restore conflict and rollback behavior before backup hardening changes runtime behavior.

## Test Matrix

| Case ID | Scenario | Input Condition | Expected Result | Gate |
| --- | --- | --- | --- | --- |
| BCON-001 | Unsupported schema | Backup schema is older or newer than accepted runtime versions. | Restore rejects before mutation. | `test:backup-schema-compatibility` |
| BCON-002 | Unknown store | Backup includes a store outside runtime inventory. | Restore rejects before mutation. | `test:backup-schema-v2-fixtures` |
| BCON-003 | Missing key | Store row omits the required key path. | Dry-run rejects before staged restore. | `test:backup-schema-v2-fixtures` |
| BCON-004 | Same key same payload | Local and backup record match. | Restore reports no-op and avoids rewrite. | `test:backup-restore-ux` |
| BCON-005 | Same key different payload | Local and backup record differ. | Restore reports conflict and applies selected policy only after confirmation. | `test:backup-restore-ux` |
| BCON-006 | Cross-owner mismatch | Backup row owner scope differs from restore scope. | Restore rejects before mutation. | `validate:backup-security` |
| BCON-007 | Encrypted checksum mismatch | Encrypted backup checksum is invalid. | Restore rejects before payload mutation. | `validate:backup-security` |
| BCON-008 | Failed staged restore | Restore validation fails after dry-run. | Existing records remain readable. | `test:backup-restore-e2e` |
| BCON-009 | Skip conflict policy | `skip-conflicts` selected. | Non-conflicting rows import and conflicting local rows remain unchanged. | `test:backup-restore-ux` |
| BCON-010 | Replace conflict policy | `replace-conflicts` selected with explicit confirmation. | Conflicting rows replace only within owner scope. | `test:backup-restore-e2e` |

## Exit Criteria

- Unsupported backup payloads reject before mutation.
- Conflict report includes store name, record key, conflict type, and selected policy.
- Failed restore does not delete or corrupt existing local records.
- Restore audit records skipped and restored counts.
