# v1.1 Command and Event Traceability Matrix

## Scope

This matrix satisfies CAND-006. It records existing local command and event evidence only. It does not add runtime behavior, persistence, migration, service worker, backend, cloud, remote scheduler, external analytics, AI, or automated financial execution.

## Governance Notes

- Contract-only stores remain `Not Implemented` for persistence until migration, backup, restore, owner-index, audit, and validation gates pass.
- Push, email, SMS, remote scheduler, backend, cloud runtime, external analytics, AI, and automated financial execution remain rejected for v1.1 active batches.
- Runtime commands and events must be added to this matrix when future batches introduce persistent command surfaces.
