# v1.1 Analytics Assessment

| Candidate | Canonical Source | Current Evidence | Excluded Risk | Decision |
| --- | --- | --- | --- | --- |
| Period Summary | Dashboard Metrics | Dashboard and projections exist | None | Could Fix |
| Category Summary | Financial Dashboard Metrics | Income/expense categories exist | None | Could Fix |
| Goal Progress Trend | Goal Progress | Current progress exists, trend history is limited | New persistence risk | Defer |
| Decision History Summary | Decision History | Decision log exists | None | Should Fix |
| Recommendation Outcome Summary | Recommendation History | Recommendation decision history exists | None | Should Fix |
| Predictive Analytics | None | None | AI/forecast scope creep | Reject |
| Remote Analytics | None | None | Telemetry/cloud | Reject |

## Result

Only local, deterministic summaries using existing data are v1.1 candidates. Predictive analytics, AI forecast, machine learning, behavior tracking, remote analytics, and telemetry are rejected.
