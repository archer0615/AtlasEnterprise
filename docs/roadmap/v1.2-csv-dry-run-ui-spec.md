# v1.2 CSV Dry-Run UI Specification

## Scope

The CSV dry-run UI previews CSV import results without writing to IndexedDB.

## Controls

- File picker for `.csv` files.
- Entity filter summary for Asset, Liability, Income, Expense, and Goal rows.
- Dry-run button.
- Clear preview button.

## Preview Output

- Total rows.
- Accepted rows.
- Rejected rows.
- Entity counts.
- Escaped error report.
- No raw HTML rendering.

## Error Report Requirements

- Formula injection cells show `FORMULA_INJECTION`.
- HTML-like cells show escaped text only.
- Path traversal-like cells show `PATH_INJECTION`.
- Prototype pollution columns show `PROTOTYPE_POLLUTION_COLUMN`.
- Duplicate IDs show `DUPLICATE_ID`.
- Cross-owner rows show `CROSS_OWNER_ROW`.

## Write Boundary

The UI must not call repository `save`, `replaceAll`, `importBackup`, or IndexedDB write APIs. Write-path import requires a future selected batch.
