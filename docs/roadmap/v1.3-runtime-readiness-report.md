## Constraints

- No backend, cloud database, authentication server, sync service, external analytics, AI runtime, remote notification, market data, broker integration, external insurance carrier integration, or automated financial execution.
- Position data must preserve owner, household, portfolio, and asset boundaries.
- Backup rollback must reject unsupported payloads before mutation.
- CSV import must preserve dry-run validation before commit.
- Insurance changes must stay local-only and IndexedDB-backed.
