# v1.3 Position CSV Test Cases

## Scope

These test cases cover Position CSV dry-run and commit readiness before runtime expansion.

## Test Matrix

| Case ID | Scenario | Input Condition | Expected Result | Gate |
| --- | --- | --- | --- | --- |
| PCSV-001 | Valid Position row | All required columns present and owner context matches. | Dry-run passes and commit plan includes one Position mutation. | `test:csv-import-write-path` |
| PCSV-002 | Missing required key | `positionId` is blank. | Dry-run rejects row before commit. | `test:csv-import-security` |
| PCSV-003 | Cross-owner row | `ownerId` differs from active owner context. | Dry-run rejects row before mutation. | `test:position-repository-contract` |
| PCSV-004 | Duplicate file key | Two rows share the same `positionId`. | Dry-run reports duplicate row conflict. | `test:csv-import-fixtures` |
| PCSV-005 | Existing record conflict | CSV row key already exists with different payload. | Dry-run reports conflict and commit is blocked. | `test:csv-import-write-path` |
| PCSV-006 | Unsupported column | CSV includes unknown column. | Dry-run reports unsupported column. | `test:csv-import-security` |
| PCSV-007 | Invalid quantity | `quantity` is zero, negative, or not numeric. | Dry-run rejects row. | `test:csv-import-fixtures` |
| PCSV-008 | Invalid timestamp | `updatedAt` is not an ISO timestamp. | Dry-run rejects row. | `test:csv-import-fixtures` |
| PCSV-009 | Position-only commit | Valid Position CSV does not include asset creation data. | Commit does not create Asset, Portfolio, Household, or Owner records. | `test:position-indexeddb-migration` |
| PCSV-010 | Backup compatibility | Position commit is followed by backup export. | Backup schema v2 remains valid and includes Position allowlisted fields only. | `test:backup-schema-compatibility` |

## Exit Criteria

- Every commit path is preceded by dry-run evidence.
- Unsupported and cross-owner rows are rejected before mutation.
- Position commit does not create related entities implicitly.
- Backup schema v2 compatibility remains green.
