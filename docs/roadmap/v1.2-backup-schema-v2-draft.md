# v1.2 Backup Schema v2 Draft

## Scope

Backup schema v2 is a draft for future payload-changing releases. It is not implemented in runtime.

## Proposed Version

- Plain backup schema: `atlas-pwa-runtime-backup.v2`
- Encrypted backup format: `atlas-pwa-runtime-encrypted-backup.v2`
- Migration source: v1 payloads remain accepted.
- Forward compatibility: v2 payloads must be rejected by v1 runtime before mutation.

## Candidate Additions

- `positions`: included only after Position persistence ships.
- `schemaCapabilities`: list of optional store payloads.
- `migrationHistory`: retained for backup restore evidence.

## Compatibility Rules

| Source Payload | Runtime | Expected Behavior |
| --- | --- | --- |
| v1 | v1 | Accepted. |
| v1 | v2 | Accepted and migrated. |
| v2 | v1 | Rejected before mutation. |
| v2 | v2 | Accepted only when all declared capabilities are supported. |

## Security Rules

- Keep checksum over minimized payload.
- Keep sensitive field masking before export.
- Reject unsafe object keys recursively.
- Reject duplicate primary keys per store.
- Reject owner-scoped stores missing owner fields.

## Exit Criteria

Backup schema v2 cannot be implemented until `npm run test:backup-schema-compatibility`, `npm run validate:backup-security`, and `npm run validate:release` pass with v2 fixtures.
