# v1.1 Notification and Calendar Limitation Audit

| Limitation | Current Position | v1.1 Decision |
| --- | --- | --- |
| Browser Closed Limitation | No runtime runs when browser is closed. | Documented limitation. |
| No Background Runtime | Scheduler is on-demand. | Keep. |
| No Push Notification | Local records only. | Reject push server. |
| No Email | Not supported. | Reject. |
| No SMS | Not supported. | Reject. |
| On-Demand Evaluation | Supported. | Keep and improve dedupe. |
| Service Worker Limitation | Static asset cache only. | Do not cache user data. |
| GitHub Pages Limitation | No server scheduler. | Keep static-first. |
| Offline Behavior | Local runtime works when app is loaded. | Keep. |
| Time Zone Behavior | Uses injected clock and date strings. | Document and test. |
| Clock Injection | Supported in tests. | Keep. |
| Duplicate Notification Prevention | Not explicit. | Could Fix. |

## Result

Browser Background Sync, Push API, and Remote Scheduler are rejected for v1.1 implementation.
