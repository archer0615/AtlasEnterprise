# v1.1 GitHub Pages Constraint Review

| Constraint | Impact | Candidate Decision |
| --- | --- | --- |
| Static Hosting | No backend processing. | Reject backend candidates. |
| Base Path | Assets must use project-safe paths. | Validate through deployment and preview smoke. |
| 404 Fallback | Static fallback only. | No server routes. |
| Service Worker Scope | Static shell cache only. | No user-data cache. |
| Cache Path | Must match static assets. | Validate PWA/offline. |
| Asset Path | Must resolve on GitHub Pages. | Validate preview smoke. |
| No Server Header Control | Cannot implement server CSP headers. | Use static audit; do not claim server CSP. |
| No Server Runtime | No scheduled or remote execution. | Reject remote scheduler. |
| No Persistent Background Process | Browser closed means no scheduler. | Document limitation. |
| No Secret Storage | No API keys or server secrets. | Reject external API runtime. |
| No Server-side Authentication | No multi-user auth. | Reject multi-user runtime. |

## Result

No v1.1 candidate may simulate a server capability with fragile client-only behavior.
