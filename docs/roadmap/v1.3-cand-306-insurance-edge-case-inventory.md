# v1.3 CAND-306 Insurance Edge Case Inventory

## Scope

CAND-306 covers local-only insurance lifecycle hardening.

## Edge Cases

| Case ID | Area | Scenario | Expected Result | Validation |
| --- | --- | --- | --- | --- |
| C306-001 | Lifecycle | Cancel already cancelled policy. | Command rejected with stable validation error. | `test:insurance-policy-domain` |
| C306-002 | Lifecycle | Update policy after cancellation. | Mutation rejected unless explicitly supported by domain rule. | `test:insurance-policy-application` |
| C306-003 | Owner isolation | List policies across owners. | Only matching owner-scoped records are visible. | `test:insurance-owner-isolation-browser` |
| C306-004 | Import | Import duplicate policy name for same owner. | Duplicate feedback shown before commit. | `test:insurance-integration` |
| C306-005 | Import | Import duplicate policy name for different owner. | No cross-owner collision. | `test:insurance-owner-isolation-browser` |
| C306-006 | Restore | Restore conflicts with existing policy. | Conflict policy is applied and reported. | `test:insurance-restore-conflict-browser` |
| C306-007 | Backup | Backup and restore policy audit history. | Audit history remains readable after restore. | `test:insurance-backup-restore-browser` |
| C306-008 | Summary | Coverage summary includes cancelled policies. | Cancelled policies are excluded or explicitly labelled by local rule. | `test:insurance-integration` |

## Exclusions

- External carrier integration.
- Claim lifecycle automation.
- Premium payment automation.
- Broker sync.
- Remote policy document storage.
- AI policy recommendations.

## Exit Criteria

- Edge cases are covered by executable tests before any behavior expansion.
- Existing insurance runtime validation aggregate remains green.
- Unsupported external workflows stay labelled as unsupported, not hidden.
