# v1.2 Position Repository Contract Draft

## Contract Status

Draft only. This contract does not authorize runtime implementation.

## Record Shape

Required fields:

- positionId
- ownerId
- householdId
- portfolioId
- assetType
- symbol
- quantity
- unitCost
- marketValue
- currency
- valuationDate
- createdAt
- updatedAt
- version

## Repository Methods

| Method | Behavior |
| --- | --- |
| create(position, idempotencyKey) | Creates one owner-scoped Position record. |
| update(positionId, patch, idempotencyKey) | Updates one owner-scoped Position record. |
| getById(positionId, ownerContext) | Returns record only for matching owner. |
| listByOwner(ownerContext) | Returns records scoped to ownerId and householdId. |
| listByPortfolio(portfolioId, ownerContext) | Returns records for one portfolio and matching owner. |
| delete(positionId, ownerContext, idempotencyKey) | Soft deletes or archives according to future lifecycle decision. |

## Rejections

- Reject missing ownerId or householdId.
- Reject cross-owner access.
- Reject negative quantity unless a future short-position spec permits it.
- Reject non-finite valuation fields.
- Reject mutation without idempotency key.
