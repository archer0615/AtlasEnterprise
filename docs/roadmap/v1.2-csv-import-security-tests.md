# v1.2 CSV Import Security Tests

## Required Security Cases

| Case | Input | Expected Behavior |
| --- | --- | --- |
| Formula Injection | values beginning with `=`, `+`, `-`, `@` | reject or neutralize in reports |
| HTML Injection | cells containing tags or event attributes | escaped rendering only |
| Path Injection | filename-like cells with `../` | treated as text only |
| Prototype Pollution | `__proto__`, `constructor`, `prototype` columns | rejected |
| Oversized Row | row over accepted size limit | rejected before write |
| Unknown Entity | unsupported entityType | rejected |
| Duplicate ID | repeated id for same owner/entity | rejected before write |
| Cross Owner | row ownerId not matching current owner | rejected |

## Validation Path

CSV import cannot enter runtime implementation until these cases have executable tests and browser-visible error reports are escaped.
