# v1.2 Position Migration Implementation Batch

## Status

Implemented.

## Scope

This batch adds the `positions` IndexedDB store and repository after backup schema v2 acceptance.

## Required Work

- Increment IndexedDB `databaseVersion` to 7.
- Add `positions` persistence inventory metadata.
- Add `positions` object store with owner, household, portfolio, asset, status, and updatedAt indexes.
- Add IndexedDB-backed Position repository with owner isolation.
- Add migration tests proving existing stores remain readable.
- Include Position records in backup schema v2.

## Required Validation

- `npm run test:position-repository-contract`
- `npm run test:position-indexeddb-migration`
- `npm run test:backup-schema-compatibility`
- `npm run validate:backup-security`
- `npm run validate:release`

## Rollback

Rollback hides runtime usage but does not delete `positions` data after any public release containing the store.
