# v1.2 CSV Dry-Run Error Report UI

## Rendering Contract

CSV dry-run error reports must render as escaped text, not HTML.

## Fields

| Field | Purpose |
| --- | --- |
| `code` | Stable validation or security error code. |
| `row` | Source CSV row number. |
| `field` | Source column name. |
| `message` | User-facing explanation. |

## Display Rules

- Sort by row number, then field name.
- Show repeated errors independently.
- Do not show raw cell values for formula, HTML, path, or prototype pollution errors.
- Keep `writeCount` visible as `0` while in dry-run mode.

## Accessibility

- Error summary uses a live region after dry-run completes.
- Error table has column headers for row, field, code, and message.
- Rejected rows remain navigable by keyboard.
