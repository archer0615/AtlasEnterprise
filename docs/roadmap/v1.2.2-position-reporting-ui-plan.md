# v1.2.2 Position Reporting UI Plan

## Scope

Position reporting UI must be read-only first.

## Required Surface

| Surface | Requirement |
| --- | --- |
| Position Summary | total market value, count, currency, status |
| Portfolio Filter | owner-scoped portfolio selection |
| Empty State | clear message when no positions exist |
| Backup Notice | shows whether positions are included in backup schema v2 |
| Accessibility | reachable heading, labelled region, keyboard focus |

## Blocked Runtime

No buy, sell, rebalance, broker sync, market price API, or automated trade execution is allowed.
