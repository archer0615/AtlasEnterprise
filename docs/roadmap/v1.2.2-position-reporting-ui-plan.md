# v1.2.2 Position Reporting UI Plan

## Scope

Position reporting UI must be read-only first.

## Required Surface

| Surface | Requirement |
| --- | --- |
| Position Summary | Complete: total market value, count, currency, status |
| Portfolio Filter | Deferred: owner-scoped portfolio selection requires a broader portfolio data selector batch |
| Empty State | Complete: clear message when no positions exist |
| Backup Notice | Complete: shows positions included in backup schema v2 |
| Accessibility | Complete: labelled region and keyboard focus |

## Blocked Runtime

No buy, sell, rebalance, broker sync, market price API, or automated trade execution is allowed.

## Closure

Position reporting UI status closure is complete for the read-only surface. Future work must remain read-only unless a dedicated migration, rollback, backup, and browser workflow batch is selected.
