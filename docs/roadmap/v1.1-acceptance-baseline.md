# v1.1 Acceptance Baseline

Every v1.1 batch must satisfy:

1. No new Domain.
2. No new Business Concept.
3. No renamed Catalog Naming.
4. No weakened Validation Profile.
5. No unplanned IndexedDB Migration.
6. No legacy Backup break.
7. No Offline break.
8. No GitHub Pages break.
9. No Backend.
10. No Remote Database.
11. No Cloud Runtime.
12. No External Analytics.
13. No Fixture Fallback in production runtime.
14. No new Financial Formula without canonical source.
15. No new Decision State Machine state.
16. No automatic Financial Operation execution.
17. No owner data leakage.
18. Security validation passes.
19. Accessibility validation path exists.
20. Visual Regression is not worsened.
21. Runtime has Canonical Traceability.
22. Persistence has Migration Test when schema changes.
23. Collection has Backup Test when persisted.
24. Critical Action has Audit.
25. Working Tree is clean after commit.
