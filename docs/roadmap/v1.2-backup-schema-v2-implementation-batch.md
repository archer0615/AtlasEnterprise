# v1.2 Backup Schema v2 Implementation Batch

## Status

Implemented.

## Scope

This batch implements backup schema v2 because the `positions` store is now part of the runtime payload surface.

## Required Work

- Add `atlas-pwa-runtime-backup.v2` validation.
- Add v1 to v2 migration path with empty `positions`.
- Add v2 fixture payloads.
- Add encrypted v2 envelope validation.
- Add unknown schema rejection before mutation.
- Add restore dry-run reporting for the `positions` store.

## Required Validation

- `npm run test:backup-schema-v2-fixtures`
- `npm run test:backup-schema-compatibility`
- `npm run validate:backup-security`
- `npm run test:backup-restore-e2e`
- `npm run validate:release`

## Rollback

v1 runtime must reject v2 payloads before mutation. v2 runtime rollback must preserve exported v2 files and continue to reject unsupported capabilities.
