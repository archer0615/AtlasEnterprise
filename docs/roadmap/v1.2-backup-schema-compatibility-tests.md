# v1.2 Backup Schema Compatibility Tests

## Scope

Backup schema compatibility must be proven before Position or Policy records are added to backup payloads.

## Compatibility Matrix

| Payload Version | Runtime Version | Expected Behavior |
| --- | --- | --- |
| current | current | dry-run and restore allowed |
| current | v1.2 | dry-run and restore allowed |
| v1.2 | current | rejected before mutation |
| v1.2 | v1.2 | dry-run and restore allowed when stores exist |
| unknown | any | rejected before mutation |

## Required Assertions

- Dry-run reports payload version.
- Dry-run reports unsupported stores.
- Restore rejects future versions without writing data.
- Encrypted backup decrypts before version validation.
- Service worker cache excludes backup payloads.
- Audit records preserve restore rejection evidence.

## Validation Path

- `npm run test:backup-restore-e2e`
- `npm run validate:backup-security`
- `npm run validate:offline`
