# v1.2.2 Backup v2 Restore UX Plan

## Scope

Backup v2 restore UX must make compatibility and rejection clear before mutation.

## Required UX States

| State | Required Display |
| --- | --- |
| Compatible v2 | store counts, checksum, dry-run accepted |
| Future Version | rejected before mutation |
| Legacy v1 With Positions | rejected before mutation |
| Encrypted Backup | decrypt first, then version validation |
| Partial Conflict | conflict policy and affected stores |

## Safety Rule

Restore cannot write data unless dry-run is accepted and the user explicitly confirms overwrite.
