## Required Gates Before Persistence

1. Add an IndexedDB migration with explicit rollback notes.
2. Add repository tests for create, update, archive, restore, owner listing, and missing-record behavior.
3. Add backup export allowlist entries for every persisted field.
4. Add restore dry-run conflict reporting for every new store.
5. Add restore tests for full import and conflict policy behavior.
6. Add audit event coverage for every critical command.
7. Add owner-index validation and runtime-boundary validation.
8. Run `npm run validate:quick` and `npm run validate:full`.
