# v1.2 Runtime Batch Selection

## Decision

No runtime batch is selected yet.

## Reason

Specification and ADR gates are documented, but Position persistence, Backup schema versioning, CSV import, and Insurance runtime still require executable tests before code implementation.

## Eligible Next Batch

The next batch should be validation-only:

- Position repository contract tests.
- Backup schema compatibility tests.
- CSV import parser security fixtures.
- Insurance command/event traceability validation.

## Not Eligible Yet

- Position IndexedDB store.
- Backup payload version change.
- CSV import UI.
- Insurance runtime UI or repository.

## Gate

Runtime implementation can be selected only after `npm run validate:feature` passes with the new validation tests included.
