# v1.2 Runtime Batch Selection

## Decision

No runtime batch is selected yet.

## Reason

Specification and ADR gates are documented. Position persistence, Backup schema versioning, and CSV import now have executable validation gates, but runtime implementation still remains blocked until a dedicated runtime batch is selected.

## Eligible Next Batch

The validation-only gate batch is complete for:

- Position repository contract tests.
- Backup schema compatibility tests.
- CSV import parser security fixtures.

Remaining validation-only work:

- Insurance command/event traceability validation.

## Not Eligible Yet

- Position IndexedDB store.
- Backup payload version change.
- CSV import UI.
- Insurance runtime UI or repository.

## Gate

Runtime implementation can be selected only after `npm run validate:feature` and `npm run validate:release` pass with the new validation tests included.
