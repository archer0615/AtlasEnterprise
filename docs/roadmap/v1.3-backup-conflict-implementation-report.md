# v1.3 Backup Conflict Implementation Report

## Scope

Implemented the first Backup conflict hardening slice from CAND-304.

## Changes

- Added `stage-only` restore policy for preview-only restore planning without mutation.
- Added `skip-conflicts` alias that maps to existing skip-existing behavior.
- Added `replace-conflicts` alias that maps to existing replace-all behavior.
- Added skipped conflict counts to restore results.
- Added conflict details with store name, key field, conflict type, selected policy, and conflict keys.
