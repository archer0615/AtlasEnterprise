## Runtime Entry Criteria

- CAND-301 is closed or explicitly deferred by the operator.
- Position owner isolation, migration, repository contract, and backup compatibility gates pass.
- CSV Position commit mapping is specified before implementation.
- Backup rollback and unsupported payload rejection tests pass.
- `npm run validate:feature` passes before runtime code is selected for release.

## Boundary

The selected runtime pair must remain static-first, local-first, offline-first, and browser-only. It must not introduce backend, cloud database, authentication server, sync service, external analytics, AI runtime, market data, broker integration, external insurance carrier integration, or automated financial execution.
