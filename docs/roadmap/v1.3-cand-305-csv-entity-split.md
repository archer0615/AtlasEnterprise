# v1.3 CAND-305 CSV Entity Split

## Scope

CAND-305 is split by entity type so CSV commit expansion remains test-first and reversible.

## Entity Candidates

| Entity | Status | Required Before Commit | Validation |
| --- | --- | --- | --- |
| Insurance policy | Implemented | Preserve dry-run, duplicate feedback, owner isolation, audit trail. | `test:insurance-runtime-validation`, `test:csv-import-write-path` |
| Position | Candidate | Confirm owner, household, portfolio, asset, status, quantity, and valuation mapping. | `test:position-repository-contract`, `test:position-indexeddb-migration` |
| Asset | Deferred | Define canonical mapping and rejection rules before write path. | `test:asset-liability-domain`, `test:csv-import-security` |
| Liability | Deferred | Define canonical mapping and repayment fields before write path. | `test:asset-liability-domain`, `test:csv-import-security` |
| Income | Deferred | Define recurring schedule and owner mapping before write path. | `test:income-expense-cashflow-domain`, `test:csv-import-security` |
| Expense | Deferred | Define category, cadence, and owner mapping before write path. | `test:income-expense-cashflow-domain`, `test:csv-import-security` |

## Commit Rule

- Dry-run must always run before commit.
- Commit must be entity-scoped.
- Unsupported columns must be reported, not silently ignored.
- Cross-owner rows must be rejected before mutation.
- Partial commit behavior must be explicitly documented before implementation.

## First Eligible Expansion

Position is the first eligible v1.3 CSV expansion candidate because position persistence and migration gates already exist. Asset, Liability, Income, and Expense remain deferred until their CSV mapping specifications are complete.
