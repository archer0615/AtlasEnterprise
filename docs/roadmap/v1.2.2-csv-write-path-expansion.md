# v1.2.2 CSV Write Path Expansion

## Scope

CSV write path expansion must stay all-or-nothing and audit-first.

## Expansion Candidates

| Entity | Status | Required Before Write |
| --- | --- | --- |
| Asset | Supported | atomic repository and audit |
| Liability | Supported | entity mapper tests, atomic unit of work |
| Income | Supported | frequency and amount validation, atomic unit of work |
| Expense | Supported | frequency and amount validation, atomic unit of work |
| Goal | Supported | target date and amount validation, atomic unit of work |
| Position | Supported by contract tests | owner and portfolio validation |
| Policy | Supported | Insurance runtime validation, atomic repository, audit |

## Required Controls

- Dry-run before commit.
- Formula injection rejection.
- Cross-owner rejection.
- Duplicate rejection before mutation.
- Audit record for every accepted commit.

## Archive Status

CSV write path expansion is archived for the currently validated local entities: asset, liability, income, expense, goal, position, and insurance policy. New entity types require a new specification, fixtures, rollback notes, and profile evidence before write support.
