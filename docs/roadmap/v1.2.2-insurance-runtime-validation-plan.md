# v1.2.2 Insurance Runtime Validation Plan

## Scope

Insurance runtime validation is executable for the local-first PWA runtime. External carrier integration remains blocked.

## Required Validation

| Area | Required Evidence |
| --- | --- |
| Domain Contract | Complete: policy identity, lifecycle, premium, coverage, unsafe beneficiary rejection |
| Command/Event | Complete for local policy create, update, cancel, and audit evidence; claims remain future scope |
| Repository | Complete: owner-scoped IndexedDB repository and owner isolation browser validation |
| Backup | Complete: policy records included in backup schema v2 with restore and conflict browser validation |
| Security | Complete: no external carrier integration, no secrets, escaped reporting |
| UI | Complete: local create/update/cancel, coverage summary, duplicate feedback, audit history |

## Exit Gate

Insurance runtime validation plan is closed for local policy records. Claim lifecycle, premium payment commands, and external carrier workflows remain blocked until separately specified and validated.
