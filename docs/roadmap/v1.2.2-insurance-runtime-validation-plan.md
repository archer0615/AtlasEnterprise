# v1.2.2 Insurance Runtime Validation Plan

## Scope

Insurance runtime remains blocked until validation is executable.

## Required Validation

| Area | Required Evidence |
| --- | --- |
| Domain Contract | Policy identity, lifecycle, premium, coverage, claim records |
| Command/Event | IssuePolicy, PayPremium, UpdateCoverage, SubmitClaim, RecordClaimPayment |
| Repository | owner-scoped in-memory contract before IndexedDB |
| Backup | policy records excluded until backup schema decision |
| Security | no external carrier integration, no secrets, escaped reporting |
| UI | read-only status surface before mutations |

## Exit Gate

Insurance runtime can be selected only after domain, application, security, and backup gates are executable.
