# v1.3 Runtime Implementation Report

## Scope

This report records the first v1.3 runtime changes completed after planning gates.

## Implemented

- Position CSV import guard hardening.
- Backup restore conflict policy hardening.

## Position CSV

- Position CSV imports no longer require the generic `name` column.
- Position rows reject unsupported non-empty columns.
- Position quantity must be greater than zero.
- Position rows validate `assetId`, `currency`, `status`, and ISO `updatedAt`.
- Position commit checks existing records before mutation and reports `CSV_EXISTING_RECORD_CONFLICT`.

## Backup Conflict

- `stage-only` restore policy returns a restore plan without mutation.
- `skip-conflicts` maps to local skip-existing behavior.
- `replace-conflicts` maps to local replace-all behavior.
- Restore results include skipped conflict counts and conflict details.
